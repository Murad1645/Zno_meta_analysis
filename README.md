# Validation-aware meta-analysis of doped-ZnO photocatalysts

Data and code accompanying:

> [Author names]. **Between-laboratory variation can exceed dopant effects: a
> validation-aware meta-analysis of literature-derived ZnO photocatalysts for
> hydrogen production.** *Digital Discovery* (2026, submitted).

This repository contains the curated dataset, the computed effect sizes, and
the complete analysis code used to produce every statistic and figure in the
manuscript and its supplementary information.

## Summary

Single-cation doping of ZnO improves photocatalytic hydrogen evolution by a
pooled 7.7\u00d7 (95% CI 3.8\u201315.4), but reported rates for nominally identical
undoped ZnO differ 1405-fold between laboratories, and knowing which study a
measurement came from fixes 98% of the information about which dopant was
used. Ranking dopants by absolute rate is therefore misleading; this
repository reproduces the within-study meta-analysis, the confounding
diagnostics, and the random-vs-study-level cross-validation ladder (7 model
families) that establish this.

## Reproducing the results

```bash
git clone <this-repository-url>
cd <repository-name>
pip install -r requirements.txt

cd code
python3 zno_meta_analysis.py      # Table 1, Figs 3-5, 7; effect_sizes.csv
python3 multialgo_leakage.py      # Table 2, Fig 6b
python3 new_figures.py            # Fig 1, Fig 2
python3 prisma_diagram.py         # Fig S1
```

Each script reads `data/ZnO_dataset_final.csv` and writes its figures to
`figures/`. All analyses use a fixed random seed (42) and the package
versions pinned in `requirements.txt`; running the scripts reproduces every
number reported in the manuscript exactly.

## Dataset

`data/ZnO_dataset_final.csv` — 59 measurements from 11 primary studies
covering 10 single-cation ZnO dopants (Ag, Ca, Ce, Co, Cu, Eu, Lu, Na, Ni,
Sr). Columns are documented in the manuscript's Methods (Section 2.2) and
Supplementary Table S1 (study characteristics, with DOIs). Two curation
corrections are already applied and documented: an inverted sign in one
electronegativity-mismatch entry (Ca) was corrected, and two records
originally logged as separate studies were identified as the same
publication and merged.

`results/effect_sizes.csv` — the 43 within-study effect sizes (log response
ratio and enhancement factor) computed from the dataset above; this is the
direct input to the meta-analysis and corresponds to Supplementary Table S2.
